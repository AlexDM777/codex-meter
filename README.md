# CodexMeter

Компактный виджет лимитов Codex для Windows: проценты, время до сброса и доступные сбросы — на рабочем столе и в трее.

**[Скачать последнюю версию](https://github.com/AlexDM777/codex-meter/releases/latest)**

## Установка

1. Установите официальный Codex и хотя бы один раз запустите его.
2. Скачайте Windows Setup из Releases или распакуйте Portable ZIP в отдельную папку.
3. Запустите CodexMeter и выберите в настройках «Войти в ChatGPT…».

Вход виджета хранится отдельно от основного Codex. Данные аккаунта не включаются в дистрибутив.

Windows 10/11 x64, .NET Framework 4.8. Встроенная копия Codex не поставляется: приложение использует установленный официальный CLI.

## Возможности

- Фактические 5-часовые и недельные лимиты из Codex, время до сброса, число доступных сбросов.
- Размер от 100 до 1000, масштабирование колесом, двойной щелчок для большого экрана.
- 16 скинов, предпросмотр при наведении, случайный скин при запуске, импорт пользовательских скинов.
- Русский, английский, немецкий, итальянский, испанский, сербский, французский, португальский.
- Плавная смена процентов и перекат цифр отсчёта; системное отключение анимаций учитывается.
- Процент в трее и подробная карточка при наведении, оформление которой соответствует скину.
- Снимок виджета в буфер обмена, прозрачность, поверх окон, автозапуск.
- Компактные WebP-фоны, качественный значок 67.

## Обновления

При запуске (с небольшой задержкой), затем раз в шесть часов приложение проверяет стабильные Releases этого репозитория. При наличии обновления в карточке трея появляется надпись и кнопка ↻. В настройках есть отдельные команды обновления приложения и обновления показателей.

«Автоматически обновлять программу» включено по умолчанию. Галочку можно снять: проверка останется, установка будет по нажатию. Программа скачивает пакет, проверяет SHA-256, закрывается, заменяет файлы и запускается снова. При неудачной замене возвращает прежние файлы. Настройки, вход и пользовательские скины сохраняются. Если папка требует прав администратора, Windows покажет обычный запрос.

Запросы обновлений идут только к GitHub Releases; личные данные Codex и токены не отправляются. Подробности для выпуска: [RELEASING.md](RELEASING.md).

## Управление

- ПКМ — меню: скины, размер, прозрачность, снимок, поверх окон и настройки.
- Наведение на миниатюру временно примеряет скин, щелчок сохраняет выбор.
- Двойной щелчок на виджете раскрывает его и возвращает прежний размер.
- Двойной щелчок на значке трея раскрывает маленький виджет, а большой скрывает.
- [Инструкция для собственных скинов](SkinGuide.md) также копируется из настроек.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\source\build.ps1
powershell -ExecutionPolicy Bypass -File .\release.ps1
```

Используется компилятор .NET Framework из Windows. Первая команда создаёт приложение и помощник обновления, вторая — ZIP, установщик, пакет обновления и SHA256SUMS в `dist`.

```powershell
.\CodexMeter.exe --self-test
.\CodexMeter.exe --custom-test
.\CodexMeter.exe --update-test
.\CodexMeter.exe --ui-test .\test-screen.png --data-dir .\test-profile
```

Последняя проверка запускает изолированный тестовый профиль; для подключения CLI нужен установленный Codex. Боевые настройки не используются.
