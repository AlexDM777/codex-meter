# Создай мой скин для CodexMeter

Помоги создать пользовательское оформление для CodexMeter 3.4 или новее. Это инструкция по формату скина, а не просьба изменять саму программу. Спроси только, какой стиль и настроение я хочу, если это ещё не описано. Отвечай на языке моего запроса.

## Что нужно выдать

Создай отдельную папку с **двумя готовыми файлами**:

1. `background.webp` — квадратный фон, предпочтительно **1024×1024**; допустимо 512–2048 по каждой стороне, WebP до 20 МБ.
2. `skin.json` — описание скина в UTF-8 по схеме ниже.

Дай мне оба файла для скачивания либо сохрани их локально в отдельной папке, если работаешь в Codex с доступом к файлам. Не ограничивайся описанием или картинкой предпросмотра. Не меняй EXE, встроенные скины, аккаунты или авторизацию Codex.

## Важно: картинка — только фон

На фоне НЕ должно быть текста, процентов, дат, времени, цифр, значков доступных сбросов, полос прогресса, шкал, внутренних таблиц или готовых кнопок. Приложение рисует их живыми данными поверх изображения.

Фактура, рамка, стекло, металл, дерево, пиксельная графика и декоративные детали разрешены. Рамка и яркий декор должны занимать не больше **12% от каждого края**. Центральную область сделай спокойной, без персонажей и контрастных объектов. Фон ориентирован прямо на зрителя, без перспективы и наклона.

Виджет сохраняет стандартную компоновку. Для одного лимита используется отдельный квадрат; для двух — две одинаковые плитки рядом. Фон также используется в числовом индикаторе 100×100, компактном 200×200 и всплывающей панели трея. Маленькая иконка трея использует выбранные цвета.

### Где программа разместит данные

Логический квадрат — 500×500. Для картинки 1024×1024 умножай координаты на 2,048:

| Элемент | Примерная область в логических координатах |
|---|---|
| Полоса прогресса | x=70–430, y=80–112 |
| Название окна лимита | по центру, y=120–148 |
| Большой процент | x=65–435, y=153–276 |
| Подпись остатка | по центру, y=280–303 |
| Крупный отсчёт до сброса | x=65–435, y=307–339 |
| Мелкая дата сброса | по центру, y=343–365 |
| Доступные сбросы | x=58–442, y=377–412 |

Не рисуй эти элементы сам: оставь под них место. Для панели трея фон может вытягиваться по высоте, поэтому не делай встроенных внутренних окошек или разделителей. Программа не поддерживает произвольный HTML/CSS, анимационные плагины или смену компоновки через skin.json.

## Формат skin.json

```json
{
  "format": "codexmeter-skin-v1",
  "id": "my-space-skin",
  "name": "Мой космический скин",
  "background": "background.webp",
  "ink": "#E6F4FF",
  "fill": "#14202A",
  "accent": "#69CAFF",
  "dark": true,
  "font": "digital"
}
```

- `id`: уникальное имя до 48 символов. Только строчные латинские буквы, цифры и дефис; первый символ — буква или цифра. Не используй точки и пути.
- `name`: понятное название от 1 до 60 символов.
- `background`: строго `background.webp`, файл рядом с JSON. Никаких URL, абсолютных путей, SVG или ссылок на чужие папки.
- `ink`: основной цвет текста и цифр.
- `fill`: цвет подложки числовой иконки трея и тонирования всплывающей панели. Подбирай близким к центральной части картинки.
- `accent`: цвет прогресса и обратного отсчёта.
- Цвета задаются строго как `#RRGGBB`, без прозрачности, CSS-функций и имён цветов.
- `dark`: логическое `true` для тёмного фона либо `false` для светлого, не строка в кавычках.
- `font`: `digital` — сегментные цифры; `sans` — обычный шрифт без засечек; `serif` — с засечками; `mono` — моноширинный. Настройка действует на основной экран и панель, компактные числа остаются сегментными.
- Не задавай служебный `number`: программа сама назначит номер, начиная с 17.

Проверь читаемость `ink` и `accent` на фоне и на `fill`. Предпочтительно не менее 4,5:1 для мелких подписей. Остаток ниже 20% программа выделяет тёплым цветом, ниже 10% — красным. Не пытайся перекрыть эти предупреждения.

## Как установить

1. В CodexMeter открыть **Настройки → Пользовательские скины → Загрузить скин…**.
2. Выбрать созданный `skin.json`. Программа проверит оба файла, скопирует их в профиль пользователя и выберет новый скин.
3. Исходную папку после успешного импорта можно перенести: приложение использует свою копию.

Хранилище пользовательских скинов:

```text
%LOCALAPPDATA%\CodexMeter\UserSkins\my-space-skin\
  skin.json
  background.webp
```

Можно положить папку туда вручную, затем выбрать **Обновить список** или перезапустить приложение. Папку удобно открыть через **Открыть папку скинов**. Служебный номер будет назначен автоматически и сохранён в JSON. Не создавай два скина с одинаковым `id`. Чтобы импортировать другую версию отдельно, используй новый `id`, например `my-space-skin-v2`.

Встроенные номера 1–16 не меняются; пользовательские скины добавляются после них. Они участвуют в случайной смене при запуске, если этот режим включён. Обновление или переустановка программы не удаляет пользовательскую библиотеку. Чтобы перенести её на другой компьютер, копируй только папки скинов, а не аккаунты, auth.json, токены или другие данные профиля.

## If the conversation is in another language

Respond in the user's language. Deliver the same two-file package: a square, text-free `background.webp` and UTF-8 `skin.json` with the exact schema above. All keys, enum values and filenames are literal; translate only the human-readable `name`. Keep the central area quiet for live quota data, use readable colors, and do not modify the application, credentials or built-in skins.

Совместимость: приложение также принимает прежние пакеты с background.png. При импорте фон автоматически сохраняется как WebP.
