# CodexMeter для macOS — первая версия

macOS 13 Ventura или новее. Один Universal-дистрибутив для Apple Silicon (M1–M5 и новее) и Intel. Использует установленный Codex CLI или CLI из Codex.app; отдельный браузер и Codex в пакет не включены.

## Установка

1. Скачайте `CodexMeter-4.0-macOS-universal.dmg` из Releases, откройте его и перенесите CodexMeter в Applications («Программы»). Можно также распаковать `CodexMeter-macOS-universal.zip` и перенести приложение в `~/Applications`.
2. Запустите CodexMeter. Проценты появятся в строке меню macOS. ПКМ открывает меню, наведение — карточку лимитов.
3. В настройках выберите «Войти в ChatGPT…». Если Codex не найден автоматически, укажите его исполняемый файл через «Путь к Codex…».

**Подпись:** первая сборка подписана ad-hoc для проверки целостности, но не имеет Developer ID и нотариализации Apple. macOS может ограничить первый запуск загруженного приложения. Для обычного доверенного распространения потребуется Developer ID владельца проекта. Не отключайте Gatekeeper. Исходники открыты, приложение можно собрать самостоятельно командами ниже.

## Управление

- Перетаскивайте виджет мышью; колесо меняет размер от 100 до 1000.
- Двойной щелчок по виджету раскрывает его до 800 и возвращает прежний размер.
- Двойной щелчок в строке меню раскрывает маленький виджет; большой — скрывает.
- В настройках — 16 скинов с миниатюрами, живая примерка, 8 языков, случайная тема, собственные скины, вход и обновления.
- Для своей темы используйте `SkinGuide.md`, положите `skin.json` рядом с `background.webp` и импортируйте JSON. PNG-пакеты тоже принимаются.
- Снимок собственного виджета отправляется в буфер обмена без записи экрана.
- Автообновления проверяют SHA-256 GitHub и подпись пакета, сохраняют предыдущий .app и перезапускают программу. Галочку можно снять.

Настройки, вход и темы: `~/Library/Application Support/CodexMeter`. Вход виджета отделён от основного Codex; приложение не копирует чужой auth.json.

## Сборка на Mac

Нужны Xcode Command Line Tools и macOS SDK. В корне репозитория:

```sh
bash macos/build.sh
build/macos/CodexMeter.app/Contents/MacOS/CodexMeter --self-test
build/macos/CodexMeter.app/Contents/MacOS/CodexMeter --render-test build/macos/previews
```

Готовые ZIP, DMG и SHA256SUMS появляются в `dist`. GitHub Actions собирает обе архитектуры, проверяет ресурсы и отрисовку на Apple Silicon, затем выполняет тесты на Intel. Без реального входа в ChatGPT эти проверки не подтверждают живую авторизацию и лимиты конкретного пользователя.
